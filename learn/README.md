# 本机学习页

通过 HTTP 静态服务访问 `learn/`。无需账号或后端。页面加载 `../data/` 的知识点、关系和真实题库，使用 `model.js` 记录事实，并复用 `DiagEngine` 评分。

学生可输入错题、自己的尝试和卡点，选择/粘贴图片并使用本机 OCR，或直接选章节。候选仅来自本地词语匹配，必须人工勾选确认。识别后的题干需核对；本页面不会理解任意照片题、生成解答或声称自动找到错因。参考答案与解析来自已有题库。

任务、草稿、当前练习和作答事件按当前孩子 ID（没有档案则匿名）与学科分别保存在 localStorage；图片保存于 IndexedDB。存储被拒绝时有明确提示，可继续当前会话并导出 JSON。OCR 不上传图片。记录与导出都不包含任何账号密钥。清除浏览器网站数据会清除记录与照片。

提交前查看样题或答案将本次作答记为使用帮助；提交后查看反馈保留首次提交时的条件，人工评分也冻结最初答案与支持条件，换新题后才重新独立检查。同题重复正确、原题重做、不同新题独立正确和到期后的复查分别记录。作答记录可人工更正或删除，并重新计算汇总。日期提醒默认 3 天，可调整，不代表经验证的通用最佳遗忘曲线。趋势展示有作答日期的实际次数，不填补无样本日期。

看过答案的样题在同一学习者、同一学科下跨任务避让；学生输入的原题也不会作为未见新题抽出。图片识别后重新核对，识别期间换图、切换学习者或修改文字不会用旧结果覆盖新内容。提交后输入冻结，改判只修正评分，保留原答案和当时的帮助条件。

支持 `?subject=math|english|chinese|physics`、`?target=知识点ID`、`?chapter=完整章节名称`。所有脚本由本站提供，无外部分析脚本。OCR使用按需加载的本地Tesseract.js；文件版本、许可和完整性见 `assets/vendor/ocr/`。
